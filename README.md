# 📊 HR Analytics Dashboard | Microsoft Excel

## 📌 Project Overview
This project is an **HR Analytics Dashboard developed using Microsoft Excel** to analyze employee data and generate meaningful HR insights.
The dashboard provides a consolidated view of important HR metrics such as employee count, attrition, active employees, attrition rate, employee demographics, education, departments, job roles, age groups, and marital status.
The objective of this project is to transform raw HR data into an easy-to-understand visual dashboard that can support better HR analysis and decision-making.

## 🎯 Objectives
- Analyze employee attrition and retention.
- Understand employee demographics.
- Identify attrition trends across departments.
- Analyze attrition based on education and age groups.
- Compare attrition across different job roles.
- Analyze employee distribution by gender and marital status.
- Present HR insights through an interactive Excel dashboard.

## 📊 Key Metrics
The dashboard includes:
- 👥 Total Employees
- 📉 Total Attrition
- 💼 Active Employees
- 📈 Attrition Rate
- 🎂 Average Age
- ⭐ Job Satisfaction Rating

## 📈 Dashboard Analysis
The dashboard contains the following visualizations:
### 1. Employee Gender Distribution
Shows the total number of male and female employees.

### 2. Education-wise Attrition
Analyzes employee attrition based on educational qualifications such as:
- Bachelor's Degree
- Master's Degree
- Associate's Degree
- High School
- Doctoral Degree

### 3. Attrition by Job Role
Shows attrition across different job roles.

### 4. Department-wise Attrition
Compares attrition across:
- HR
- R&D
- Sales

### 5. Attrition by Age Group
Analyzes attrition across different age groups.

### 6. Attrition by Marital Status
Shows attrition based on:
- Married
- Single
- Divorced

### 7. Interactive Filters
The dashboard includes filters for:
- Education Field
- Department
- Gender

## 💡 Key Insights
The dashboard helps identify:
- Overall employee attrition levels.
- Departments with higher attrition.
- Job roles experiencing greater employee turnover.
- Education groups with higher attrition.
- Age groups contributing to attrition.
- Differences in attrition based on marital status and gender.
